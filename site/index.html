Muscle Spindle Tutorial

An interactive app for exploring a biophysical model of the muscle spindle. Move a parameter and watch the fiber forces and the sensory signal respond. No MATLAB needed.

1Watch the tutorial

The video was recorded with an earlier version of the app. It works the same way; a few plots look slightly different.

2Download the app

Older Mac? If Apple menu → About This Mac says "Intel", use the version for Intel Macs instead.

3Install and open it

On a Mac
  1. Open your Downloads folder and double-click the zip file to unzip it.
  2. Right-click SpindleTutorialInstaller and choose Open, then click Open again. (A normal double-click is blocked the first time, because the app isn't from the App Store.)
  3. Follow the installer. It downloads a free component from MathWorks, so it needs the internet and can take a while.
  4. To open it, go to Applications → Spindle_Tutorial → application and double-click SpindleTutorial. If macOS warns you, right-click it and choose Open. (Tip: drag it to your Dock to find it easily next time.)
On Windows
  1. Open your Downloads folder, right-click the zip file and choose Extract All.
  2. Right-click SpindleTutorialInstaller and choose Run as administrator.
  3. If a blue "Windows protected your PC" box appears, click More info, then Run anyway.
  4. Follow the installer. It downloads a free component from MathWorks, so it needs the internet and can take a while.
  5. The installer offers to add a desktop shortcut: tick it, then open Spindle Tutorial from your desktop. (Otherwise it's in the folder the installer showed you, inside application.)
The first time you open it, the app can take a minute to start. After that it's quicker.

?Have MATLAB?

You can run it from the source code instead, which also includes tools for fitting the model to your own data. See the project on GitHub.
